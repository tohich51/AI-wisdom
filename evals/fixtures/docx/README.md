# DOCX fixtures

Every file here is **generated by `build_fixtures.py` and contains nothing real**.
No document from any library, project or person is in this directory, and none
is downloaded at test time. The builder writes them with python-docx 1.2.0 (MIT),
so what the tests read is a real OOXML package — a real ZIP with a real
`[Content_Types].xml` and a real `word/document.xml` — rather than a dictionary
shaped like one.

```
python evals/fixtures/docx/build_fixtures.py            # rewrite in place
python evals/fixtures/docx/build_fixtures.py /tmp/where # write elsewhere
```

The build is byte-reproducible. That is not free: a ZIP stores a modification
time per entry and takes it from the clock, so an unnormalised rebuild differs
by however many seconds separated the two runs. `build_fixtures.py` rewrites
each package with a fixed 1980-01-01 timestamp after saving.
`test_the_builder_and_the_committed_fixtures_agree` in
`tests/integration/parsers/docx_fixtures_test.py` compares SHA-256 against a
fresh rebuild, so a fixture that was hand-edited afterwards fails the suite
instead of quietly becoming something the parser was never tested against.

| file | what it is for |
| --- | --- |
| `basic.docx` | two headings, four paragraphs, one of them blank, and a plain 2x3 table. The numbering rule: the blank paragraph must still consume a number. |
| `nested_table.docx` | a 2x2 table with a 2x2 table inside cell (2, 2), which also carries a paragraph of its own. |
| `merged_cells.docx` | one 3x3 table with a horizontal `w:gridSpan` merge on the first row and a `w:vMerge` chain down the first column. |
| `exotic_runs.docx` | hyperlink, tracked insertion, tracked deletion, an inline content control, a field result next to its instruction code, a text box, a body-level content control, an `mc:AlternateContent` and an `altChunk`. |

`exotic_runs.docx` exists to make the parser's refusals testable. Every one of
those constructs has a defensible case for being read *and* a defensible case
for being left alone, and the parser picks one and says so. Reading all of them
silently would put text in a fragment that no locator addresses; refusing them
silently would lose text nobody was told about.
