# Synthetic book fixtures

Every file in this directory is **generated by a test**, byte for byte, by
`tests/integration/parsers/pdf_fixtures.py` and
`tests/integration/parsers/epub_fixtures.py`. None of them is a real book, none
was downloaded, and none contains text from anywhere but those two modules. A
test (`test_the_committed_fixtures_are_exactly_what_this_module_generates`)
asserts the committed bytes are identical to what the generator produces, so
the two cannot drift.

They exist so that a parsing test can assert *which* file page carries *which*
printed label, and *which* spine position carries *which* paragraph. A fixture
that came from elsewhere could only be asserted against.

| file | what it is for |
|---|---|
| `text_book.pdf` | 4 typed pages whose declared printed labels (`i`, `ii`, `1`, `2`) disagree with their file pages (1–4) |
| `authored.pdf` | 1 typed page, no `/PageLabels` tree, an author the file states |
| `scan.pdf` | 2 pages that draw an image and no text: a page-less scan |
| `booklet.epub` | 3 spine documents with headings, paragraphs, a list and a table |
| `anonymous.epub` | the same book with no creator anywhere |
| `scan.epub` | one spine document holding an image and no text |

**These files must never be preloaded into a production library.** A test in
`tests/integration/parsers/pdf_parsing_test.py` walks `src/`, `migrations/` and
`deploy/` and fails if any of them names this directory or any file in it.
Nothing ships them: the product receives the owner's own uploads.
