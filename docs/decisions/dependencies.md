## Правило

устанавливается spike-карточками, а не предполагается. Если библиотека
вынуждает заменить выбранную архитектуру — это blocker/proposal, а не тихая
подмена.

## Библиотека браузерного OAuth · 20.10.2026

Authlib 1.8.0 закреплён в существующих lockfiles и используется в
AuthorizationCodeFlow: строит authorization URL с S256 PKCE и выполняет обмен
кода через fetch_token. Параметры протокола не собираются вручную.

Общий httpx 0.28.1 передаётся в generic OAuth2Client через session.
Встроенная HTTPX-интеграция Authlib 1.8 использует отдельный httpx2; она здесь
не нужна. Для каждого шага создаётся отдельный объект протокола, поэтому
mutable token state не переносится между браузерами. Соединения остаются
в существующем HTTP-пуле. HTTPX выполняет стандартный client_secret_basic.

Проверка подписи, issuer/audience/nonce остаётся у PyJWT/TokenVerifier,
discovery/JWKS — у httpx, одноразовый state, binding и сессии — в PostgreSQL.
Сроки сессий, CSRF и права не расширяются. Ответ провайдера обязан быть
HTTP200 и JSON-объектом; наружу попадают только фиксированные коды отказа.

Проверены существующие 30 сценариев браузерного потока и отдельный реальный
обмен кода в текущем Keycloak realm с временным синтетическим пользователем.
Сессия этого сценария хранится только в временной PostgreSQL, не в рабочей
базе. Пользователь удаляется по точному ID с проверкой удаления.
Сведения о парсерах и лицензиях: [Parser provenance](parser-provenance.md).

## Ограничения среды, влияющие на установку

1. **pip в этой песочнице**: дефолтный индекс не работает ни для одного
   пакета. Рабочая конфигурация —
   `--index-url https://pypi.org/simple/ --trusted-host pypi.org --trusted-host files.pythonhosted.org`.
   Это зашито в `justfile` (PIP_INDEX) и безвредно на обычном хосте.
2. **PEP 668**: системный Python защищён, поэтому `just prepare` создаёт `.venv`.
3. `requirements.lock` — авторитетный pin-набор (60 строк, сгенерирован из
   реально установленного набора). `uv.lock` в этом handoff не генерировался:
   uv 0.12.17 присутствует, но канонический lock выбранного формата
   фиксируется на C36 по результатам приёмки.

## Исторические ограничения исходной cloud-среды · 09.10.2026

- `mcp` 2.3.0 импортируется, но **второй независимый MCP-клиент в этой среде
  отсутствует**. A01–A20 по MCP-ноге не исполнимы здесь → E03 pending.
- OpenViking не устанавливался и не запускался (C04).
- В исходной cloud-среде отсутствовала JVM. Это историческое ограничение; текущий Keycloak запускается с собственной JVM в контейнере. Актуальный статус подтверждают runtime receipts.
